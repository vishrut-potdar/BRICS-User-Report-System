# Data sources: status and sourcing checklist

Ten packs ship: five countries at state level and one district-level pilot each (see `docs/schema.md`). Boundaries
and populations are real (see `data/LICENSE-DATA.md`); every indicator value is still a flagged placeholder. Each pack
config lists, per metric, the official source to use (`expected_source`): IBGE and SINISA/SNIS for Brazil, Rosstat
for Russia, NITI Aayog/NFHS-5/JJM for India, NBS/MWR/NHC for China, Stats SA Census 2022 for South Africa. Drop the
extracts in `data/raw/<PACK>/` (format in `data/raw/README.md`).

The checklist below is the most advanced one, for the Maharashtra pilot.

## Maharashtra (IN-MH)

**Current state:** every indicator value is a deterministic PLACEHOLDER (flagged in `indicators_long.csv`, in
`district_indicators.csv` → `placeholder_metrics`, and in the API under `/meta` and `/districts`). The district
list, names and aspirational flags are real. The 2011 population figures were entered from memory and are marked
`population_verified=false`: check them against the Census 2011 Primary Census Abstract.

Work down this list; after each file run `python -m scripts.build_indicators --allow-placeholder` from `backend/`.

Community-parsed CSVs exist; if you use one, cite both it and the original fact sheet.

## Known limitations to state in the deck

- NFHS-5 and MPI 2023 describe 2019-21. Census 2011 is the latest population base until Census 2027 results arrive
  after its February 2027 enumeration.
- Maharashtra district renames (Ahilyanagar, Chhatrapati Sambhajinagar, Dharashiv) are handled as aliases.
  Palghar was carved from Thane in 2014; the 2011 figures split them.
- District-level need is coarse: within-district variation is carried only by the demand clusters.

## Synthetic data (`data/synthetic/<PACK>/`)

Generated by `scripts/generate_synthetic.py` (seed 42, CC BY 4.0), one set per pack. Requests cluster around each
unit's most populated places. Each `manifest.json` records every assumption: digital-connectivity multipliers (urban
units file more), language mix, location-confidence mix, and the planted brigading attack (200 messages from 12
numbers in 30 minutes, roads; Pune in Maharashtra, Maceió in Alagoas, Kyzyl in Tuva, and so on). Treat any headline number
computed on it as illustrative, and recompute after real indicators land.
