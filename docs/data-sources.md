# Data sources: status and sourcing checklist (Maharashtra pack)

**Current state:** every indicator value is a deterministic PLACEHOLDER (flagged in `indicators_long.csv`, in
`district_indicators.csv` → `placeholder_metrics`, and in the API under `/meta` and `/districts`). The district
list, names and aspirational flags are real. The 2011 population figures were entered from memory and are marked
`population_verified=false`: check them against the Census 2011 Primary Census Abstract.

Work down this list; after each file run `python -m scripts.build_indicators --allow-placeholder` from `backend/`.

The NFHS-5 fact sheets (items 2-4) come as one PDF per district, so a single pass covers three metrics.
Community-parsed CSVs exist; if you use one, cite both it and the original fact sheet.

## Known limitations to state in the deck

- NFHS-5 and MPI 2023 describe 2019-21. Census 2011 is the latest population base until Census 2027 results arrive
  after its February 2027 enumeration.
- Maharashtra district renames (Ahilyanagar, Chhatrapati Sambhajinagar, Dharashiv) are handled as aliases.
  Palghar was carved from Thane in 2014; the 2011 figures split them.
- District-level need is coarse: within-district variation is carried only by the demand clusters.

## Synthetic data (`data/synthetic/`)

Generated by `scripts/generate_synthetic.py` (seed 42, CC BY 4.0). `manifest.json` records every assumption:
digital-connectivity multipliers (urban districts file more), language mix, location-confidence mix, and the
planted brigading attack (200 messages from 12 numbers in 30 minutes, roads, Pune). Treat any headline number
computed on it as illustrative, and recompute after real indicators land.
